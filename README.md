# Nasiru Lawal Kwargana — portfolio

Editorial one-page site built with Next.js, Tailwind CSS, and Framer Motion.

Live: [https://meastronass.github.io/myportfolio/](https://meastronass.github.io/myportfolio/)

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Pages

Pushes to `main` build a static export and deploy via GitHub Actions. In the repo: **Settings → Pages → Source: GitHub Actions**.
